02.

Agentic hiring system

When
September 2026
Role
Design lead
For
Recruiter platform

Business goals

Be an AI-first full process recruitment platform and deepen use of the hiring system.

User goals

Increase efficiency and enable many different possibilities on top of the hiring system platform.

Context

With the Hiring system live and new users onboarding onto it, the opportunity for super-powering Alva with an agent became clear. Alva Labs has always stood on a strong foundation of structured hiring and scientific evidence. Combining this knowledge with AI workflows to increase efficiency, reduce admin and disperse hiring knowledge seemed like a natural next step.

The agent across hiring

The Alva agent is backed by and educated on hiring research and structured processes, and is therefore uniquely qualified to help users in all parts of the hiring process.

Users can do anything from creating reports and reviewing their pipeline to having the agent actually act for them. It can run the pipeline, schedule and transcribe interviews, and automate predictable admin steps.

Customers who are not on the full hiring system can also buy into the agent, without the agent workflows.

Agent principles

Hiring is a sensitive process and in order to remain trustworthy the agent cannot make any decisions on its own. All assessment and scoring actions that could directly impact a candidate’s chances at a job must be reviewed by a human.

September 2026

Alva agent release

Releasing the agent and agentic workflows that reduce admin and increase user efficiency.

Key functionality

  1. Agent chat
  2. Action hub
  3. Agent workflows
  4. Agentic interview scheduling and transcriptions
  5. Career pages

My role

🧭Design the core agent experiences, from the agent chat on the homepage to the Action hub where recruiters approve or dismiss the agent’s suggestions.

🔗Ensure that all the upcoming and ongoing functionality has related agent flows, so that users of the chat agent can complete their jobs to be done.

🧪Prototype and test agent workflows with customers early, and use their feedback and usage data to decide what to build next.

Outcomes

3x number of users with multiple agent chats in a span of 1 month
